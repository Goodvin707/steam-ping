Уведомления о библиотеке

Новая игра в библиотеке друга приходит в Discord.

Процесс сам сверяет открытую библиотеку Steam. Новая игра уходит в Discord без команд и без кнопки на этой странице. «Показать пример» только рисует карточку здесь.

Как подключить

Покупка, подарок и бесплатная раздача выглядят одинаково: Steam отдаёт только факт, что игра теперь в библиотеке.

Автоотправка

Проверяю, подключён ли канал.

Канал → Изменить канал → Интеграции → Вебхуки → Новый вебхук → Скопировать URL. Адрес сохраняется на этой машине и в ответ панели не возвращается. После включения сверка идёт сама, примерно раз в десять минут.

Кого смотрю

Лента

Подключение

  1. Ключ Steam. steamcommunity.com/dev/apikey — значение кладётся в STEAM_API_KEY. У друга в приватности должен быть открыт пункт «Сведения об играх».
  2. Канал, который получает сообщения сам. Создай вебхук и вставь его в блок «Автоотправка», либо пропиши DISCORD_WEBHOOK_URL и WATCH_STEAM_IDS в .env. Процесс должен оставаться запущенным. Первая сверка запоминает текущие игры и молчит, следующие шлют только новые.
  3. Бот с командами — по желанию. Портал разработчика → Bot → Reset Token → DISCORD_TOKEN. Привилегированные интенты не нужны. Для мгновенных команд укажи DISCORD_GUILD_ID. В канале: /channel, затем /watch. У каждого сервера свой список и свои снимки библиотек: покупка, замеченная на одном, на другой не уходит.
