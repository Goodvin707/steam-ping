# Как запустить Steam Ping бесплатно

Сайт хостить не нужно. Программа стоит на твоём компьютере, сама спрашивает Steam и сама пишет в канал Discord. Панель `http://127.0.0.1:8741` открывается только у тебя в браузере. В интернет её выставлять не надо: для уведомлений она не используется.

Пока окно с программой закрыто или компьютер спит, проверки останавливаются. Это весь «хостинг».

## Что понадобится

- Python 3.11 или новее.
- Обычный аккаунт Steam. Ограниченному аккаунту ключ API не выдают.
- Сервер Discord, где ты можешь создать вебхук в нужном канале.
- Открытые «Сведения об играх» у друга. Закрытая библиотека для программы пустая.

Вебхук — это пароль от канала. Его нельзя отправлять людям, класть в чат и коммитить в git.

## 1. Поставить Python

Скачай установщик с [python.org/downloads](https://www.python.org/downloads/).

На Windows в установщике отметь **Add python.exe to PATH**.

## 2. Открыть папку проекта

Все команды ниже выполняются в папке, где лежат `requirements.txt` и `.env.example`.

## 3. Поставить зависимости

Windows:

```bat
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

macOS и Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## 4. Ключ Steam

Открой [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey), будучи залогиненным в Steam.

В поле домена напиши `localhost`. Скопируй ключ в файл `.env`:

```env
STEAM_API_KEY=сюда_ключ
```

## 5. Вебхук Discord

В нужном канале: **Изменить канал → Интеграции → Вебхуки → Новый вебхук → Скопировать URL вебхука**.

Вставь адрес в `.env`:

```env
DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/...
```

Бот Discord и токен для этого пути не нужны.

## 6. Профиль друга

Друг в Steam открывает приватность профиля и ставит **Сведения об играх** в Public.

Его ссылку положи в `.env`. Несколько друзей пишутся через запятую.

```env
WATCH_STEAM_IDS=https://steamcommunity.com/id/nickname
```

Подойдут также vanity и SteamID64.

## 7. Запустить

Windows, в той же папке и с включённым `.venv`:

```bat
python -m app
```

macOS и Linux:

```bash
python -m app
```

Окно не закрывай.

## 8. Проверить, что заработало

В канал Discord сразу приходит одно сообщение: автоотправка включена. Это проверка связи, не покупка.

Первая сверка только запоминает игры, которые у друга уже лежат в библиотеке, и в канал о них не пишет. Карточка уходит сама, когда появится новая игра. Пауза между сверками — 10 минут (`POLL_INTERVAL_SECONDS=600` в `.env`, минимум 60).

Панель, если захочешь на неё посмотреть: [http://127.0.0.1:8741](http://127.0.0.1:8741). Её можно не открывать вообще.

## Чтобы компьютер не усыпил программу

Windows: Параметры → Система → Питание → экран можно гасить, сон на время работы программы выключи.

Закрыл терминал — уведомления встали. Снова запусти `python -m app` из папки проекта с активированным `.venv`.

Файл `.env` и папка `data` с запомненными библиотеками должны остаться на месте. Если удалить `data`, первая сверка снова пройдёт молча и заново запомнит текущие игры.

## Что программа считает покупкой

Steam не присылает событие «купил». В канал уходит факт «в открытой библиотеке появилась игра, которой не было в прошлом снимке». Так же выглядят подарок и бесплатное получение. Дополнения, саундтреки и демо не отправляются. Дата покупки в API нет.
