# Steam Ping

Discord-бот, который пишет в канал, когда в открытой библиотеке друга в Steam появляется новая игра.

Steam не присылает событие «купил». Бот запоминает список игр через официальный Web API и сравнивает его со следующим снимком. Покупка, подарок и бесплатное получение выглядят одинаково: в библиотеке просто появляется новая позиция. Первая сверка молчит и только запоминает то, что уже есть.

Если «Сведения об играх» у профиля закрыты, смотреть нечего. Дополнения, саундтреки и демо в канал не отправляются. Пачка из десятков игр сразу считается открытием библиотеки, а не ночью распродаж, и в Discord не сыпется.

## Запуск

Пошаговый бесплатный запуск без сайта и без хостинга: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

Коротко: ключ Steam, вебхук канала и ссылка на друга в `.env`, затем `python -m app`. Окно программы должно оставаться открытым. Панель `http://127.0.0.1:8741` локальная, в интернет её выставлять не нужно.

Нужен Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app
```

Панель: [http://127.0.0.1:8741](http://127.0.0.1:8741)

Отправка уже автоматическая. Кнопка «Показать пример» только рисует карточку на панели и в Discord не пишет. Живой профиль проверяется в фоне: первая сверка запоминает библиотеку, дальше новая игра уходит в канал сама.

Самый короткий путь: `STEAM_API_KEY`, `WATCH_STEAM_IDS` и `DISCORD_WEBHOOK_URL`. Либо вебхук вставляется в блок «Автоотправка» на панели, без перезапуска. Процесс должен оставаться запущенным. Команды `/watch` и `/channel` нужны только если вместо вебхука используется бот.

Проверки:

```bash
pytest
```

## Что положить в `.env`

| Переменная              | Зачем                                                                         |
| ----------------------- | ----------------------------------------------------------------------------- |
| `STEAM_API_KEY`         | Ключ с [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey) |
| `DISCORD_TOKEN`         | Токен бота с [портала Discord](https://discord.com/developers/applications)   |
| `DISCORD_GUILD_ID`      | ID сервера, чтобы команды появились сразу, а не в течение часа                |
| `WATCH_STEAM_IDS`       | Ссылки, vanity или SteamID64 через запятую                                    |
| `NOTIFY_CHANNEL_ID`     | Канал, если не хочешь выбирать его командой `/channel`                        |
| `DISCORD_WEBHOOK_URL`   | Вебхук канала: вместе со списком друзей включает автоотправку                 |
| `POLL_INTERVAL_SECONDS` | Пауза между сверками, по умолчанию 600, минимум 60                            |
| `DEMO_MODE`             | `auto` оставляет пример, пока не заданы оба ключа                             |

Привилегированные интенты Discord не нужны. В приглашении должны быть scope `bot` и `applications.commands` и права писать в канал и вставлять ссылки. Готовая ссылка появляется на панели, когда токен на месте.

Команды видны тем, у кого есть право управлять сервером:

- `/watch` — начать следить за профилем
- `/unwatch` — убрать профиль
- `/list` — кто в списке
- `/channel` — писать в этот канал
- `/check` — сверить библиотеки сейчас
- `/status` — ключ, канал, интервал
- `/test` — тестовое сообщение, это не покупка

Процесс должен работать постоянно: закрыл терминал — сверки остановились. Для своей машины подойдёт systemd или просто сессия, которая не засыпает.

## Границы

- Дата покупки в API нет, есть только «этой игры не было в прошлом снимке».
- Возврат и повторное появление той же игры второй раз не объявляются.
- Короткий или внезапно огромный ответ Steam не превращается в пачку уведомлений.
- Ключ Steam и токен Discord остаются в `.env` и на панель не выводятся.
